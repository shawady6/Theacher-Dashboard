# إدارة المجموعات الدراسية — النسخة 2 (Supabase + PWA)

## خطوات التشغيل (مرة واحدة)
1. **قاعدة البيانات:** افتح Supabase ← SQL Editor ← New query ← الصق محتوى `schema.sql` ← Run.
2. **الرفع على GitHub Pages:** ارفع كل محتويات هذا المجلد (بما فيه مجلد `icons`) في جذر المستودع،
   ثم Settings ← Pages ← Deploy from a branch ← `main` / root.
3. افتح رابط الموقع (HTTPS) من الموبايل أو الكمبيوتر، وبعدها "تثبيت التطبيق".
4. لو عندك بيانات في النسخة القديمة: التطبيق هيعرض عليك رفعها تلقائيًا لو لقاها على نفس الجهاز،
   أو من ⚙ إعدادات متقدمة ← استيراد (ملف JSON من النسخة القديمة).

## ملاحظات
- لا يوجد تسجيل دخول: أي شخص يعرف الرابط يقدر يقرأ ويعدّل ويمسح البيانات.
- لتغيير مشروع Supabase عدّل `SUPABASE_URL` و`SUPABASE_KEY` أعلى `app.js`.
- لتحديث التطبيق بعد النشر: ارفع الملفات الجديدة وغيّر `VERSION` في `sw.js`.
- لتغيير شكل الأرقام (أرقام هندية ١٢٣): غيّر `NUM_LOCALE` في `app.js` إلى `"ar-EG"`.

## الإصدار 4 — التنقل الجديد
- الشريط السفلي (موبايل): الرئيسية · المجموعات · المدفوعات · الحضور · المزيد.
- **المجموعات** = المجموعات + الطلاب في صفحة واحدة (شرائح المجموعات فوق، وتحتها كارت المجموعة وطلابها). على الكمبيوتر بتتقسم نصين.
- **المزيد** = الامتحانات، التقرير الشهري، الإعدادات المتقدمة، المظهر، تثبيت التطبيق.
- لتحديث الموقع على GitHub Pages: ارفع كل الملفات (sw.js اتحدّث لـ v4.0.0 عشان الكاش القديم يتبدّل).
